# 01 · 数据来源与数据字典

## 1. 数据集来源

| 项目 | 内容 |
| --- | --- |
| 数据集名称 | 链家（Lianjia）北京二手房成交记录 |
| 覆盖范围 | 北京市 13 个行政区，成交时间 2011-11 ~ 2017-02 |
| 记录规模 | 原始 318,851 条（清洗后约 30 万条），26 个字段 |
| 原始编码 | GB18030（直接按 UTF-8 读取会乱码，流水线首步即做编码探测） |
| 许可协议 | CC0-1.0（Public Domain） |
| 主要获取地址 | GitHub：`https://github.com/Logical-Dhruv/housing-price-in-beijing` → `new.csv`（58.4 MB） |
| 同源参考地址 | Kaggle：`dhruvconnects/beijing-housing-price-cleaned`（该仓库的清洗版） |
| 上游说明 | 原始数据采集自 Lianjia.com 公开成交页面，经社区整理后开源 |

> **可复现性说明**：本项目的默认数据源 `lianjia_bj_raw` 指向上述 GitHub 直链，
> 通过 `python tools/etl.py download --source lianjia_bj_raw` 即可重新拉取。
> 每次导入都会计算原始文件的 **SHA-256** 并写入数据版本记录，用于校验数据未被篡改。

## 3. 目标变量与业务区间

- **预测目标**：`unit_price`（成交单价，元/㎡）。选择单价而非总价，是因为总价 = 单价 × 面积，
  用总价建模会把「面积」这一信息重复计入，而单价更能反映区位与品质的市场定价。
- **业务合理区间**（`schema.VALID_RANGES`）：单价 3,000–200,000 元/㎡；总价 20–15,000 万；
  面积 10–1,000 ㎡；建成年份 1900–2020；梯户比 0–1；挂牌天数 0–4,000 天。
  超出区间的记录被视为异常值，由异常值处理策略统一处置。

## 4. 已知数据局限（影响结论边界，必须声明）

| 局限 | 具体表现 | 本项目处理方式 |
| --- | --- | --- |
| 无用户 ID | 无法构造真实「用户-房源」交互矩阵 | 协同过滤使用**参数化行为模拟日志**（种子固定、协议公开）；同时在**真实数据**上单独评估相似房源检索 |
| 时间跨度较早 | 数据止于 2017-02，不能代表当前市场 | 所有模型结论限定在「样本期内的相对规律」，不用于当下定价 |
| 类别编码不透明 | 部分编码语义无法完全确证 | 保留 `未知` 兜底，不臆测 |
| 无挂牌价 | 只有成交价，无法研究议价空间 | 明确标注，不作为本项目结论 |
| 无房屋朝向/学区字段 | 影响定价的重要因子缺失 | 通过小区均价、经纬度做部分代理，并在特征消融实验中量化其贡献 |

## 5. 数据使用合规

数据为公开、CC0 许可的历史成交记录，仅用于教学与算法研究；本项目不对数据准确性、
完整性作任何担保，不得用于商业定价或投资决策。
